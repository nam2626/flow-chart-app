# Quickstart: 프레젠테이션 컴포넌트 전환 및 PNG 내보내기

## 사전 조건
- 애플리케이션이 실행 중이어야 한다.
- 캔버스 폭은 300~400px 범위로 설정된 상태여야 한다.

## 시나리오 1 (P1): 프레젠테이션 전용 컴포넌트 전환
1. 편집 화면에서 도형 2개 이상과 본문 텍스트를 입력한다.
2. 프레젠테이션 시작을 실행한다.
3. 확인: 편집용 입력/버튼이 사라지고 프레젠테이션 전용 컴포넌트가 표시된다.
4. 확인: "단계 1", "단계 2" 같은 단계 번호 텍스트는 보이지 않는다.

## 시나리오 2 (P2): 화살표 경계 및 리디자인 검증
1. 크기가 다른 도형 3개를 순서대로 배치한다.
2. 프레젠테이션 화면을 확인한다.
3. 확인: 화살표 시작점이 시작 도형의 경계에 위치한다.
4. 확인: 화살표 끝점이 대상 도형 경계 4px 앞에서 멈춘다.
5. 확인: 도형 채움/테두리/화살표 색상이 리디자인 토큰과 일치한다.

## 시나리오 3 (P3): PNG 내보내기 성공
1. 유효한 도형 텍스트가 모두 입력된 상태에서 PNG 내보내기를 실행한다.
2. 확인: 프레젠테이션 전용 화면 기준 PNG 파일 다운로드가 시작된다.
3. 확인: 성공 메시지가 표시된다.

## 예외 시나리오
1. 도형 텍스트가 비어 있는 상태에서 PNG 내보내기를 실행한다.
2. 확인: 실패 메시지와 사유 코드가 표시되고 파일은 생성되지 않는다.
3. 단계가 1개인 상태에서 프레젠테이션을 시작한다.
4. 확인: 전용 컴포넌트는 표시되지만 다음/이전 이동은 비활성화된다.

## 성능 스모크
1. 50단계 데이터로 프레젠테이션 시작을 10회 반복해 p95를 측정한다.
2. 50단계 화살표 계산을 10회 반복해 p95가 300ms 이하인지 확인한다.
3. 50단계 PNG 내보내기 피드백 표시 p95가 700ms 이하인지 확인한다.

## SC-004 14일 비교 집계 템플릿
- 기준 기간(배포 전): YYYY-MM-DD ~ YYYY-MM-DD
- 비교 기간(배포 후): YYYY-MM-DD ~ YYYY-MM-DD
- 지표:
  - 프레젠테이션 시작 수
  - PNG 내보내기 시도 수
  - PNG 내보내기 성공률
- 계산식:
  - 성공률 = 성공 이벤트 수 / 시도 이벤트 수 * 100
