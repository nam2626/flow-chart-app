# Quickstart: 단계형 플로우차트 보강

## 사전 조건
- 애플리케이션 실행 가능 상태
- 기본 편집 화면 진입 가능

## 시나리오 1 (P1): 단계 작성 + 자동 화살표 연결
1. 빈 차트를 연다.
2. 단계 3개를 추가하고 각 단계 텍스트를 입력한다.
3. 확인: 도형이 세로로 나열되고 1->2, 2->3 화살표가 표시된다.
4. 두 번째 단계 텍스트를 비운 후 저장/내보내기를 시도한다.
5. 확인: 텍스트 누락 검증 메시지가 표시되고 완료 동작이 차단된다.

## 시나리오 2 (P2): 캔버스 폭 입력 제한
1. 폭 입력값으로 `350`을 입력한다.
2. 확인: 캔버스 가로폭이 즉시 350px로 반영된다.
3. 폭 입력값으로 `299`, `401`, `abc`를 순서대로 입력한다.
4. 확인: 값이 적용되지 않고 허용 범위(300~400) 오류 메시지가 표시된다.

## 시나리오 3 (P3): 내보내기 복구
1. 유효한 3단계 차트를 준비한다.
2. 내보내기를 실행한다.
3. 확인: 파일이 정상 생성된다.
4. 의도적으로 유효하지 않은 데이터(빈 텍스트 단계)로 내보내기를 실행한다.
5. 확인: 실패 원인과 수정 안내 메시지가 표시된다.

## 성능 검증 스모크
1. 50단계 샘플 차트를 로드한다.
2. 단계 추가 후 화면 갱신 p95가 300ms 이내인지 확인한다.
3. 폭 변경 반영 p95가 300ms 이내인지 확인한다.
4. 내보내기 시작이 5초 이내인지 확인한다.
