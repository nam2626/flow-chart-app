# Quickstart: 도형 관리 및 프레젠테이션 모드

## 사전 조건
- 애플리케이션 실행 가능 상태
- 기본 편집 화면 접근 가능

## 시나리오 1 (P1): 단일 삭제 및 전체 초기화
1. 단계 도형 3개를 생성한다.
2. 두 번째 도형을 삭제한다.
3. 확인: 삭제 즉시 반영되고 남은 순서는 1..N으로 재정렬된다.
4. 전체 초기화를 실행하고 확인한다.
5. 확인: 도형/연결/프레젠테이션 상태가 비워지고 캔버스 설정이 기본값으로 복원된다.

## 시나리오 2 (P2): 프레젠테이션 시작과 단계 이동
1. 단계 도형 3개(텍스트 입력 완료) 상태를 준비한다.
2. 프레젠테이션 모드를 시작한다.
3. 확인: 첫 단계 강조 상태가 표시된다.
4. 다음/이전 이동을 실행한다.
5. 확인: 강조 대상과 현재 단계 표시가 순서에 맞게 갱신된다.

## 시나리오 3 (P3): 프레젠테이션 종료 후 편집 복귀
1. 프레젠테이션 모드에서 단계 이동을 1회 이상 실행한다.
2. 프레젠테이션 종료를 실행한다.
3. 확인: 편집 화면으로 복귀하고 도형 데이터 손실이 없다.

## 예외 시나리오
1. 프레젠테이션 중 현재 강조 도형을 삭제한다.
2. 확인: 삭제가 즉시 반영되고 다음 유효 단계(없으면 이전 단계)로 강조가 이동한다.
3. 도형 없는 상태에서 삭제/초기화를 실행한다.
4. 확인: 시스템 오류 없이 안내 메시지가 표시된다.

## 성능 스모크
1. 50단계 샘플 차트를 로드한다.
2. 단일 삭제 반영 p95가 300ms 이내인지 확인한다.
3. 전체 초기화 반영 p95가 300ms 이내인지 확인한다.
4. 프레젠테이션 단계 전환 반영 p95가 300ms 이내인지 확인한다.
