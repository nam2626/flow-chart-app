# Quickstart: 간단 웹 플로우차트 작성기

## 1. 준비

- Node.js 20+
- npm 10+
- 브라우저: Chrome/Edge/Safari 최신 2개 메이저 버전

## 2. 설치 및 실행

```bash
npm install
npm run dev
```

## 3. 핵심 시나리오 검증

1. 편집 화면에서 사각형/타원 노드를 3개 추가한다.
2. 각 노드의 단계 순서(stepOrder)를 1, 2, 3으로 지정한다.
3. 단축키 `N` 입력으로 다음 단계 이동을 확인한다.
4. 현재 단계 노드에만 outglow 효과가 적용되는지 확인한다.
5. 캔버스 폭을 300, 4000으로 각각 설정해 경계값 동작을 확인한다.

## 4. 저장/불러오기 검증

1. JSON으로 내보내기 후 다시 불러온다.
2. 기존 캔버스와 병합되고 충돌 발생 시 해결 UI가 표시되는지 확인한다.
3. 사용자 미선택 시 기본값이 가져온 파일 우선으로 적용되는지 확인한다.
4. 5MB 초과 파일은 불러오기 거부 및 안내 문구 표시를 확인한다.
5. SVG 내보내기 결과가 화면 상태와 시각적으로 일치하는지 확인한다.

## 5. 테스트 실행

```bash
npm run test:unit
npm run test:integration
npm run test:e2e
```

## 6. 성능 확인 기준

- 단계 전환 결과가 0.3초 이내에 화면에 반영된다.
- 5MB 이하 파일 import 결과가 3초 이내에 완료된다.
- 200 노드 상태에서 선택/이동 조작 시 체감 지연이 없다.

## 7. 검증 증적

- US1/US2/US3 핵심 시나리오 실행 결과를 스크린샷 또는 로그로 보관한다.
- UI 변경 PR에는 변경 전/후 비교 자료를 포함한다.
