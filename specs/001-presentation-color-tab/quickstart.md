# Quickstart: 도형 색상 커스터마이징 및 새탭 프레젠테이션 정렬 개선

## 사전 조건
- 애플리케이션이 실행 중이어야 한다.
- 최소 3개 도형이 생성 가능한 상태여야 한다.

## 시나리오 1 (P1): 도형별 색상 지정 및 유지
1. 편집 화면에서 도형 3개를 생성한다.
2. 각 도형에 서로 다른 채움색/테두리색을 지정한다.
3. 확인: 각 도형에 지정한 색상이 즉시 반영된다.
4. 페이지를 새로고침한다.
5. 확인: 도형별 색상 설정이 유지된다.

## 시나리오 2 (P2): 새탭 프레젠테이션 중앙 정렬
1. 프레젠테이션 시작을 실행한다.
2. 확인: 별도 새탭 프레젠테이션 화면이 열린다.
3. 확인: 도형 흐름이 가로 중앙 정렬로 렌더링된다.
4. 새탭 열기 차단 환경에서 다시 시도한다.
5. 확인: 시작이 취소되고 명시적 오류 메시지가 표시된다.

## 시나리오 3 (P3): 강조/화살표 중심점 검증
1. 프레젠테이션 실행 후 특정 단계를 활성화한다.
2. 확인: 활성 도형 box-shadow opacity가 baseline 대비 2배(최대 1.0)로 적용된다.
3. 확인: 인접 도형 화살표의 시작/종료점이 각 도형 중심점과 일치한다.

## 성능 스모크
1. 50단계 데이터로 새탭 프레젠테이션 시작을 10회 반복 측정한다.
2. 확인: p95가 300ms 이하.
3. 50단계 중심점 화살표 재계산을 10회 반복 측정한다.
4. 확인: p95가 300ms 이하.

## 실패 시나리오 점검
1. 브라우저 팝업 차단을 활성화한 뒤 프레젠테이션 시작을 시도한다.
2. 확인: 시작이 취소되고 "새 탭 열기 차단" 오류 메시지가 노출된다.
3. 색상 입력 값을 비정상 값으로 주입한다(테스트 코드 기준).
4. 확인: 기본값 채움색/테두리색으로 fallback 된다.
