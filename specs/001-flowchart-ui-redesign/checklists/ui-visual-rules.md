# UI Visual Rules Checklist: Flowchart UI Redesign

## Structure And Hierarchy

- [ ] Top toolbar is visually separated as action area
- [ ] Left rail is grouped into Shapes and Layers/Steps blocks

## Spacing And Alignment

- [ ] Section headings use consistent spacing scale
- [ ] Control rows use consistent vertical rhythm
- [ ] Canvas and panel blocks keep balanced gutters
- [ ] Connector flow remains center aligned in workspace

- [ ] Migration impact documented (or explicitly none)
